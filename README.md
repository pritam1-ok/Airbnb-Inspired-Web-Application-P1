# 🏡 Airbnb-Inspired Web Application

A full-stack Airbnb-inspired web application that enables users to discover, list, and manage rental properties through a modern and responsive interface. The application replicates the core functionality of a vacation rental platform, including secure user authentication, property management, image uploads, and an intuitive booking experience.

## ✨ Features

* 🔐 Secure user authentication and authorization
* 🏠 Create, edit, and delete property listings
* 📸 Upload and manage property images
* 🔍 Browse and search available accommodations
* 📱 Fully responsive UI for desktop and mobile devices
* ⭐ User-friendly interface inspired by Airbnb
* 🗄️ MongoDB database integration for persistent data storage
* ⚡ RESTful API architecture for seamless frontend-backend communication

## 🛠️ Tech Stack

**Frontend**

* React.js

* CSS3
* JavaScript

**Backend**

* Node.js

**Database**
